# Digimon World 2 Run Planner & Battle Simulator v1.4.3

This release includes the Phase 2P-D Planner location/mapping corrections.
It changes Planner location/mapping behavior, not canonical combat stats or
battle formulas.

## Coliseum

Rank 8-B and 8-C now reference the correct canonical encounters. Displayed order
remains A / B / C:

| Rank | Encounter | Lineup |
| --- | --- | --- |
| 8-A | 176 | AeroVeedramon / Garudamon / Mammothmon |
| 8-B | 178 | WaruMonzaemon / Megadramon / Tekkamon |
| 8-C | 177 | Deramon / Blossomon / Pumpkinmon |

Canonical encounters themselves are unchanged. Existing Run history receives
the corrected labels from stored encounter IDs without persisted-data migration
or rewriting events.

## Core Tower

The Guardian boss location is corrected from Floor 17 to **Floor 24**.
The initial starter's canonical species type determines the Guardian:

| Initial starter | Type | Encounter | Guardian |
| --- | --- | --- | --- |
| Gold Hawk / Agumon | Vaccine | 148 | VaccineGuardian |
| Blue Falcon / Patamon | Data | 146 | DataGuardian |
| Black Sword / DemiDevimon | Virus | 150 | VirusGuardian |

Only the matching Guardian is selectable for a known Run. Resolution uses
`RunPlan.starterDefinitionId` and canonical starter species type, never current
Digiline composition or evolved form. Recording rejects mismatched variants,
and boss capture remains unavailable. Analyze Battle preserves the exact
recorded Guardian encounter and boss metadata.

Floor 17 retains its normal encounters; no Floor 23 encounter was added.
Guardian canonical stats and techniques are unchanged. Canonical encounter
records 146, 148, 150, 177 and 178 were not modified.

## Compatibility

No changes were made to WAZADATA, battle damage, Guardian encounter stats or
techniques, Planner schema, Simulation Report version or Backup Format version.
Application version **1.4.3** remains independent of **Planner schema 7**,
**Simulation Report 1** and **Backup Format 1**.
