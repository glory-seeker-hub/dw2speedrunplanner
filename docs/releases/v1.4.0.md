# Digimon World 2 Run Planner & Battle Simulator v1.4.0

## Highlights

- Corrected empirical damage arithmetic from the merged Phase 2P-A update, using the shared battle engine across simulation and search consumers.
- Fractional AP is preserved through the offensive product until final damage truncation. Fire Blast retains AP 17.5; the premature AP/offensive-product floor is removed.
- ATK/type truncation follows the validated order: floor effective ATK, apply the type multiplier, then floor again before multiplying by AP and the remaining offensive factors. Divide by adjusted DEF and floor final base damage.
- Positive ATK and DEF stages use **+1 = 1.5x** and **+2 = 2x**, with each nonzero stage calculated and floored directly from the base stat.
- Canonical DEF Down applies before damage on the same hit. DEF -1 uses the empirical fit `floor(base DEF * 180 / 256)`; DEF -2 uses `floor(base DEF / 2)`.
- Scissor Claw and Duo Scissor Claw both validate **26 / 36 damage** at ATK 120 against original DEF 132: the first hit reduces DEF to 92, and the next stage reduces it to 66. Both retain raw AP 40 / displayed AP 20 without name-based exceptions.

## Validation

The full suite passes **3,484 tests**, including dedicated empirical and integration regressions. Both TypeScript checks and the production build pass. Lint retains the existing baseline of 3 errors and 7 warnings.

See the [Phase 2P-A empirical damage report](../phase-2p-a-empirical-damage.md) for observations, arithmetic details and evidence limits, and the [release checklist](v1.4.0-release-checklist.md) for release verification status.

## Known limitations

- ATK Down and SPD stages retain the preceding model; these experiments do not validate their arithmetic.
- Terrain arithmetic and its placement are preserved. Terrain interactions with the ATK/type truncation boundaries still need dedicated experiments.
- DEF -1's 180/256 multiplier fits the supplied observations; it is not an assembly-level finding. The game's exact assembly arithmetic is not established.
- Fractional Planner stats and legacy modifier composition remain compatibility extensions beyond the observed integer game model.

Damage, KO timing and selected routes can change as a result of the merged arithmetic correction. Search strategies, RNG policy, timing constants and canonical WAZADATA are unchanged.

Application version **1.4.0** is independent of **Planner schema v7**, **Simulation Report v1** and **Backup Format v1**, which remain unchanged. This release preparation only updates package versions and release documentation.
