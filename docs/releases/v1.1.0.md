# Digimon World 2 Run Planner & Battle Simulator v1.1.0

## Highlights

- Select the allowed simulation techniques for each Player Digimon without modifying Run Planner or Team Builder data. Historical Planner battles and manual teams are supported, with all source techniques enabled by default. Filters work alongside exact stat overrides and apply to Random and Optimized search.
- Explicit Player targeting for Interrupts and single-target Counters is included in simulation decisions and optimized search.
- Recommended Player Orders show actual targets from retained fastest executions, including Assist recipients and activated Counter targets. Screened strategies retain intended or policy labels where recipients vary by rollout.
- Corrected eligibility for Necro Magic, Hyper Flashing, Virus Attack, and Heart Break Hit.
- Regression-tested Counter behavior for Meteor Stream, Energetic Bomb, and Smiley Warhead.
- Added a [video tutorial](https://www.youtube.com/watch?v=2mG2kCHFp4Y) to How to Use, with a responsive privacy-enhanced embed and an external fallback link.

## Battle / Search Notes

Player Interrupts target the selected Enemy only. They trigger immediately before that Enemy's valid, interruptible Hit; a failed opportunity does not retarget. Enemy Interrupts preserve their existing first-eligible-action behavior in actual execution order. Misses remain non-interruptible.

An untriggered single-target Player Counter uses its original selected target at the end of the turn and does not randomly retarget if it becomes invalid. Activation can override that target with the causal attacker or all eligible opponents for all-on-counter techniques. Original order intent remains distinct from effective reaction targets.

Meteor Stream, Energetic Bomb, and Smiley Warhead use one target when untriggered and AoE when activated. Smiley Warhead retains its activated 1.5× damage-output multiplier, applied after base damage calculation rather than to AP. Meteor Stream and Energetic Bomb have no additional 1.5× counter-output bonus.

Necro Magic requires a KO target on either side with zero current HP and positive current MP. Hyper Flashing requires a living opposing Vaccine Digimon; Virus Attack requires a living opposing Virus Digimon; Heart Break Hit requires a living opposing Data Digimon. These eligibility rules apply symmetrically to Player and Enemy users.

Explicit reaction-target choices can increase optimized root-plan counts. Technique filters reduce the effective skill set used to compute those counts and the minimum search budget. Simulation Report v1 records the effective skill list. Planned orders that never execute remain marked as unexecuted, without fabricated resolved targets.

## Limitations

Search is bounded and sampled; it does not guarantee the global optimum. TAS Luck controls only supported modeled outcomes. Battle frames exclude external menu/order-entry overhead. Player HP/MP depletion does not stop the offensive simulation; required recovery, revival, Guard, and item actions are not automatically inserted or counted.

Planner data is browser-local. Backups are explicit local JSON files; there are no accounts, cloud sync, or automatic backups. Export Route and Simulation Report are not restorable Planner backups.

Application version 1.1.0 is independent of Planner schema v7, Simulation Report v1, and Backup Format v1.
