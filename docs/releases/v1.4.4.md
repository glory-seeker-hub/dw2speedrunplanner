# Digimon World 2 Run Planner & Battle Simulator v1.4.4

This patch release includes the Phase 2P-E correction to Fantasmic random-element
handling and GAIA1 Analyze Battle.

## Analyze Battle

GAIA1 encounter **151** in **Chaos Tower / after Blood Knights / Floor 20** can
now be opened through Analyze Battle. The historical preset retains canonical
GAIA1 stats and its three techniques: **Titan Laser / Fantasmic Bomb / GAIA Gear**.
No synthetic Basic Attack or fallback is introduced. GAIA2 / encounter **152**
remains supported.

Previously, Fantasmic Bomb's canonical element representation could cause
Analyze Battle to fail before navigation to Battle Simulation. Fantasmic Bomb
now shares Fantasmic Ray's supported random-element semantics.

## Fantasmic random element

**Fantasmic Bomb (`0xF1`)** and **Fantasmic Ray (`0xF4`)** select one of **Water /
Fire / Nature / Machine / Darkness** per successful execution. The chosen
effective element participates in normal damage behavior, including specialty
matchup and floor/tile specialty calculation, and is exposed in execution audit
and impact diagnostics.

One execution uses one selected element across all its impacts. Later executions
draw again; misses do not consume a Fantasmic element draw. The existing
`fantasmic-element` RNG category and Fantasmic Ray's draw order are preserved.
No new TAS Luck semantics were introduced.

## Canonical data

WAZADATA and byte4 are unchanged. Canonical `element === null` remains preserved
for both Fantasmic skills, IDs **[241, 244]**. This nonstandard encoding does not
mean Neutral and is not converted into a fixed Neutral/None element. The decoder
does not return a random-element enum.

The shared production semantic definition recognizes exactly **241 (`0xF1`)**
and **244 (`0xF4`)**. Other null-element skills are not automatically accepted.
The legacy compatibility representation's None placeholder is not the actual
attack element; damage uses the execution-time effective element.

## Compatibility

There are no changes to Planner schema, Simulation Report version, Backup Format
version, encounter stats, damage formula, specialty matrix, floor bonus formula,
or WAZADATA source bytes. Application version **1.4.4** remains independent of
**Planner schema 7**, **Simulation Report 1**, and **Backup Format 1**.
