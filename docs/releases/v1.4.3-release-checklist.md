# v1.4.3 release verification

See the [release notes](v1.4.3.md) and
[Phase 2P-D evidence](../phase-2p-d/BATTLE-MAPPING-CORRECTIONS.md).

## Verified development facts

- Coliseum Rank 8 displays A / B / C with encounter IDs **176 / 178 / 177**.
- Existing history resolves corrected rank labels from stored encounter IDs;
  persisted events require no migration or rewrite.
- Core Tower's Guardian boss is on **Floor 24**, with one physical location.
- Initial starter mapping: Gold Hawk / Vaccine → **148 VaccineGuardian**;
  Blue Falcon / Data → **146 DataGuardian**;
  Black Sword / Virus → **150 VirusGuardian**.
- Resolution uses `RunPlan.starterDefinitionId` and canonical starter species
  type, never current Digiline composition or evolved form.
- A known Run offers only its matching Guardian. Recording rejects mismatched
  variants; boss capture remains unavailable.
- Analyze Battle preserves the recorded encounter and boss metadata.
- Normal Floor 17 encounters remain unchanged; no Floor 23 encounter was added.
- Canonical encounters **146, 148, 150, 177 and 178** remain unchanged, including
  Guardian stats and techniques.
- Focused Phase 2P-D tests: **696 passed**, including 12 new regressions.
- Complete suite: `node --test tests/*.test.cjs` — **3,532 passed**.
- TypeScript app: `npx tsc -p tsconfig.app.json --noEmit` passed.
- TypeScript node: `npx tsc -p tsconfig.node.json --noEmit` passed.
- Production build: `npm run build` passed; existing Browserslist-age and
  chunk-size warnings remain.
- Lint: `npm run lint` unchanged at **3 errors / 7 warnings**.
- `git diff --check`: passed.

These are Planner location/mapping corrections, not canonical combat-stat or
battle-formula corrections. WAZADATA, battle damage, Guardian stats/techniques,
Planner schema, Simulation Report version and Backup Format version are unchanged.
Application version **1.4.3** remains independent of **Planner schema 7**,
**Simulation Report 1** and **Backup Format 1**.
