# Digimon World 2 Run Planner & Battle Simulator v1.3.0

## Highlights

- Planned Single-target actions whose selected target is KO'd before execution now resolve as a Miss instead of a free skipped action: **194 frames**, **0 MP**, no impacts and no ordinary accuracy/on-hit RNG.
- Battle timing now includes measured processing/order-entry overhead between rounds: **319 frames** for 1 living Player ally, **385** for 2, or **452** for 3. Enemy count does not affect this overhead.
- No transition overhead is charged before Round 1 or after the battle-ending round.
- Random, Optimized, TAS Luck and capture-qualified searches all use the updated canonical totals. Fewer-round strategies may now outrank routes with slightly shorter action animations but extra round transitions.
- Results and Simulation Reports expose action-frame and round-transition timing breakdowns. About this application and How to Use explain the updated timing.

## Timing behavior

A valid locked target lost before execution produces a resolved Miss, costing exactly 194 frames and 0 MP, with no impacts or ordinary accuracy RNG. The intended target remains available in the action audit. Pending actions after battle end remain skipped.

Each actual next-round start adds one deterministic transition charge. Living Player allies are counted by current HP above zero at that boundary. Zero living allies has no measured transition duration and makes the full timing unavailable.

For example, **2,443 action frames + 452 transition frames = 2,895 total frames**.

This includes the measured inter-round processing/order-entry interval. Unrelated, unmodeled external menu, setup, recovery and item time remains excluded.

## Limitations

- Optimized Search is bounded and sampled; it does not prove global optimality.
- TAS Luck controls only supported modeled RNG outcomes.
- External recovery, item and setup actions can remain outside modeled battle timing.
- Planner data is browser-local. Backups are explicit local files; there is no account or cloud synchronization.

Application version **1.3.0** is independent of **Planner schema v7**, **Simulation Report v1** and **Backup Format v1**, which remain unchanged.
