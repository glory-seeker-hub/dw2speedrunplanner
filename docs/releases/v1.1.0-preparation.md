## Limitations and acceptance

Retained limitations: bounded/sampled search is not a global optimum; TAS controls only supported modeled outcomes; frames exclude external menu/order-entry overhead; Player HP/MP depletion does not insert recovery/revival/Guard/items or stop offensive simulation; Planner storage is browser-local with explicit backups and no account/cloud sync; Report/Export Route are not Planner backups. Manual saved teams last only for the app session. See the public release notes for the user-facing limitations.
