# v1.4.4 release verification

See the [release notes](v1.4.4.md) and
[Phase 2P-E evidence](../phase-2p-e/FANTASMIC-RANDOM-ELEMENT.md).

## Verified development facts

- Random-element skill IDs are exactly **0xF1 (241)** and **0xF4 (244)**.
- Fantasmic Bomb and Fantasmic Ray share `isRandomElementSkillId()` and
  `RANDOM_ELEMENT_SKILL_IDS` in `src/utils/battleSkillSemantics.ts`.
- Allowed execution elements are **Water / Fire / Nature / Machine / Darkness**.
- The effective element reaches normal damage calculation, including specialty
  matchup and floor/tile specialty calculation.
- One successful execution uses one chosen element for every impact; later
  executions draw again. Misses do not consume the Fantasmic element draw.
- The existing `fantasmic-element` RNG category and Fantasmic Ray's draw order
  are preserved. No new TAS Luck semantics were introduced.
- Execution audit records `Random attack element: <element>`; impact diagnostics
  expose the effective element.
- GAIA1 encounter **151**, Chaos Tower / after Blood Knights / Floor 20, produces
  a valid Analyze Battle preset with canonical stats and **Titan Laser /
  Fantasmic Bomb / GAIA Gear**, without synthetic Basic Attack or fallback.
- GAIA2 encounter **152** remains supported with Fantasmic Ray.
- Canonical WAZADATA and byte4 are unchanged. Canonical `element === null`
  remains preserved for IDs **[241,244]**; it does not mean Neutral. Only the two
  explicitly recognized IDs receive random-element semantics.
- Focused Phase 2P-E tests: **303 passed**, including **27 Fantasmic regressions**.
- Complete suite: `node --test tests/*.test.cjs` — **3,561 passed**.
- TypeScript app: `npx tsc -p tsconfig.app.json --noEmit` passed.
- TypeScript node: `npx tsc -p tsconfig.node.json --noEmit` passed.
- Production build: `npm run build` passed; existing Browserslist-age and
  chunk-size warnings remain.
- Lint: `npm run lint` unchanged at **3 errors / 7 warnings**.
- `git diff --check`: passed.

Application version **1.4.4** is independent of **Planner schema 7**,
**Simulation Report 1**, and **Backup Format 1**. These format versions,
encounter stats, damage formula, specialty matrix, floor bonus formula, and
WAZADATA source bytes are unchanged.

## Public smoke-test procedure

### GAIA1 Analyze Battle

Using a Run with the Chaos Tower / after Blood Knights / Floor 20 GAIA1 battle
(encounter 151) recorded:

- Click Analyze Battle and confirm navigation to Battle Simulation.
- Confirm GAIA1 appears as the enemy.
- Confirm Titan Laser, Fantasmic Bomb, and GAIA Gear are present.
- Confirm no synthetic/basic fallback technique appears.

### Fantasmic execution

Where practical, run a simulation involving Fantasmic Bomb or Fantasmic Ray.
Verify execution diagnostics can report `Random attack element: <element>` and
the displayed/recorded effective element is Water, Fire, Nature, Machine, or
Darkness. Manually proving all five outcomes is not required; deterministic
automated tests already cover all five for both techniques.

### GAIA2 regression

Confirm Analyze Battle for GAIA2 encounter 152 still opens successfully.
