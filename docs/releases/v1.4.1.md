# Digimon World 2 Run Planner & Battle Simulator v1.4.1

## Phase 2P-B targeting fixes

- Fixed Friendly Fire targeting. It now follows canonical `targetGroup === 'one-ally'`, allowing its own user or another living same-side Digimon as the recipient. Friendly Fire never normally targets an opponent.
- Canonical one-ally targeting includes self for Friendly Fire, verified in-game with BizHawk. This empirical observation directly validates Friendly Fire; it does not claim that every canonical `one-ally` technique was individually tested in-game. Shared generic behavior remains unchanged beyond the targeting correction.
- Fixed activated Counter targeting when the triggering attacker is an ally. A Single Counter triggered by an enemy still targets the causal attacker; one triggered by an ally now targets one random living opponent. Activated AoE Counters still target all living opponents.
- Confusion replacement remains authoritative and may still cause allied targeting.
- Added the dedicated RNG category `counter-friendly-trigger-target` for same-side-trigger Counter target selection. A sole living opponent requires no target-selection draw.
- Random Simulation, explicit Player targeting, Optimized Action Search, replay and report target identities use the corrected behavior.

There are no WAZADATA, damage-arithmetic, battle-timing, schema or search-policy changes. Friendly Fire's canonical effects remain unchanged. Application version **1.4.1** is independent of **Planner schema v7**, **Simulation Report v1** and **Backup Format v1**.
