# Digimon World 2 Run Planner & Battle Simulator v1.4.2

## MasterTyrannomon canonical specialty correction

MasterTyrannomon's canonical specialty is corrected from **Machine** to **None**;
its type remains **Vaccine**. Power Domain F2 boss encounter 157 automatically
inherits the corrected canonical `mastertyrannomon` species. Its stats remain
HP 520, MP 520, ATK 70, DEF 60 and SPD 63.

This correction fixes damage calculations affected by the specialty matchup.
Four supplied BizHawk measurements now match the planner exactly:

| Technique | Observed | Simulated |
| --- | ---: | ---: |
| Thunder Ray | 76 | 76 |
| Pummel Peck | 76 | 76 |
| Evil Charm | 62 | 62 |
| Fire Blast | 54 | 54 |

A reviewed self-check enforces **MasterTyrannomon specialty is None**. Dedicated
regressions cover canonical data, encounter resolution and the shared production
damage calculation.

No change was made to `battleDamage.ts`, damage arithmetic, DEF Down arithmetic,
type or specialty matrices, WAZADATA, technique data, encounter 157 stats,
Planner schema, Simulation Report version or Backup Format version.
Application version **1.4.2** remains independent of **Planner schema 7**,
**Simulation Report 1** and **Backup Format 1**.
