# Digimon World 2 Run Planner & Battle Simulator v1.0.0

Suggested GitHub Release body. Release preparation only; not published or deployed.
Proposed tag: `v1.0.0` (create only after production smoke).

## Highlights

- Run Planner with multiple saved runs, progression tracking, and historical Analyze Battle.
- Team Builder and manual battle setup, including exact simulation stats.
- Random Monte Carlo and Optimized Action Search with Fastest Potential, Average Victory, and Success Rate objectives.
- Standard / Thorough / Maximum Search Thoroughness and Natural / TAS Luck.
- Simulation Report and Markdown export, plus local Run Planner JSON backup/import.
- Story and Coliseum encounters, with complete How to Use documentation.

## Limitations

Search is bounded and sampled; it does not guarantee the global optimum. TAS Luck controls only supported modeled outcomes. Battle frames exclude external menu/order-entry overhead. Player HP/MP depletion does not stop the offensive simulation; required recovery, revival, Guard, and item actions are not automatically inserted or counted.

Planner data is browser-local. Backups are explicit local JSON files; there are no accounts, cloud sync, or automatic backups. Export Route and Simulation Report are not restorable Planner backups.

Application version 1.0.0 is independent of Planner schema v7, Simulation Report v1, and Backup Format v1.
